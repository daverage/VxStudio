📋 Installation Instructions

macOS

  1. Download the macOS ZIP
  2. Extract the archive
  3. Copy the .vst3 bundles to /Library/Audio/Plug-Ins/VST3
  4. Restart or rescan your DAW

Windows

  1. Download the Windows ZIP
  2. Extract the archive
  3. Copy the .vst3 bundles to C:\Program Files\Common Files\VST3
  4. Restart or rescan your DAW

Need help? See detailed installation guide or contact support.
