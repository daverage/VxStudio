Support

Common help routes for installation, plugin scanning, and understanding the suite.

Plugin not showing up

Rescan VST3 plugins in your DAW and confirm the .vst3 bundles are in /Library/Audio/Plug-Ins/VST3 (macOS) or C:\Program Files\Common Files\VST3 (Windows). See the installation guide for step-by-step instructions.

Need product guidance

The product detail section and signal chain guide on the homepage explain each plugin's role. The repository README has full usage notes and example settings for every plugin.

Bug reports

Open an issue on GitHub Issues. Include your DAW, OS version, and what you were doing. Regression test failures should include the failing test name and the build hash.

Build / source questions

Build instructions are in the README. The REAPER preset pack lives under assets/reaper/ — one .RPL library per effect plus scenario-based .RfxChain starting chains.
