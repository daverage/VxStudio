Installation Guide

Current build installation steps for the VX Studio plugin suite.

macOS

Download the archive from Downloads, extract it, copy `.vst3` bundles into `/Library/Audio/Plug-Ins/VST3`, then rescan plugins in your DAW.

Windows

The Windows build is still in progress. The downloads page will be updated when the first supported package is ready.

What It Looks Like

Once the bundles are installed and rescanned, the suite opens into these familiar product panels.
